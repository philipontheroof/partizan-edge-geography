Hex Edge Geography

시작 위치 선택 중
P1 시작 vertex를 선택
Branch 0

규칙

1. P1, P2가 시작 vertex를 하나씩 선택.
2. 자기 턴에 현재 vertex와 edge로 연결된 이웃 vertex를 클릭.
3. 이동에 사용한 edge는 즉시 삭제.
4. 상대가 있는 vertex로도 이동할 수 있으며, 별도 승리 판정은 하지 않음.
5. 자기 턴에 이동 가능한 edge가 하나도 없으면 패배.

분기

과거 턴으로 돌아간 뒤 다른 수를 두면 기존 진행은 유지되고 새 분기가 생긴다. 아래 트리의 점을 클릭하면 그 상태로 바로 이동한다.
